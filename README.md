# 我是梗王

《我是梗王》使用原生微信小游戏运行环境开发，直接调用小游戏 Canvas、触摸事件和本地存储 API。完成微信版本后，通过独立平台适配层迁移到抖音小游戏。

## 当前工程状态

- 微信小游戏基础工程配置与竖屏启动入口
- 首页与可滚动关卡树的交互原型
- 微信运行时封装，包含系统信息、存档、触摸和前后台事件
- 关卡 JSON 样例

答题界面、计时、判题和结算仍待开发。界面当前使用 Canvas 绘制占位图形与 Emoji，后续接入正式美术资源。

## 目录

```text
game.js                 微信小游戏入口
game.json               小游戏运行配置
project.config.json     微信开发者工具工程配置
src/game/app.js          页面绘制和触摸交互
src/platform/index.js    平台 API 边界
data/levels.json         关卡数据
images/                  游戏图片资源
```

## 运行

1. 安装并打开微信开发者工具。
2. 导入本项目根目录。
3. 使用自己的小程序 AppID 替换 `project.config.json` 中的 `touristappid`。
4. 编译并在模拟器预览，或连接真机调试。

目前环境没有替换成正式 AppID，也没有在微信开发者工具中验证运行。
